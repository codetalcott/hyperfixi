Localized live counters

Three counters, three languages, one shared reactive variable ($global_count). Each counter is a hyperscript live block written in its section's language — Spanish en-vivo … fin, Japanese ライブ … 終わり, Arabic مباشر … نهاية. The hyperscript adapter translates each one to English as the engine reads it (the attribute stays as written), and the engine's dependency tracking does the rest: clicking any button updates the shared variable and all three counters re-render in lockstep.

What you should see

Clicking +1, −1, or reset updates the shared $global_count. All three counters — Spanish, Japanese, Arabic — re-render to the same number: each is the same live put $global_count or 0 into me in another language, which the adapter turns back into English before the engine runs it. The translation is @lokascript/semantic's render of the English, so the three attributes are exactly what translate_code gives for them.
