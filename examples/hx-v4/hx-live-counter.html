live counter

The number below is rendered by <div _="live put $count into me">. Writing $count from any handler re-runs the live body: the engine tracks what the body read, and nothing else wakes it.

0

What's happening

  1. hyperfixi-hs.js loads: the engine, hyperscript only. Its live feature (src/reactivity.ts, following upstream's live / when / bind) is part of the bundle; nothing to install.
  2. The engine reads _="live put $count into me" and runs the body once, recording every variable, property, attribute and query it read as a dependency.
  3. Each button writes $count with a plain set. A write schedules the effects that read that variable for the next microtask; the live body re-runs.
  4. The raw-JS button writes through hyperfixi.evaluate(…), so the write goes through the same runtime and is seen the same way.
