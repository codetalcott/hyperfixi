SSE — hx-sse:connect

Real htmx 4 with its hx-sse extension, loaded beside hyperfixi-hs.js. The element below streams /fake-stream (text/event-stream) and swaps each event's HTML into #feed with hx-swap="afterbegin". This page mocks fetch for the demo URL with a streaming response, so it runs without a backend.

What's happening

  1. hx-sse sees hx-sse:connect="/fake-stream", fetches it, and reads the text/event-stream body as it arrives.
  2. Each unnamed event's data: is HTML; htmx swaps it into hx-target with hx-swap="afterbegin", newest first.
  3. A named event (event: progress) would be dispatched as a DOM event instead; a hyperscript handler on the engine can listen to it (_="on progress …") or to htmx's own htmx:sse:after:message.
