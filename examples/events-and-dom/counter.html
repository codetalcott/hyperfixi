Counter

Increment and decrement values
Learn how to modify numeric values with hyperscript's increment and decrement commands.
increment decrement numbers
0

Current value: 0

The Code

<div id="count" class="counter-display">0</div> <button _="on click decrement #count's textContent"> Decrease </button> <button _="on click put 0 into #count"> Reset </button> <button _="on click increment #count's textContent"> Increase </button>

How it works:

  • increment #count's textContent - Adds 1 to the counter's value
  • decrement #count's textContent - Subtracts 1 from the counter's value
  • put 0 into #count - Resets the counter to zero

Advanced Increment/Decrement:

  • increment #count's textContent by 5 - Add 5 instead of 1
  • decrement #count's textContent by 10 - Subtract 10
  • increment my value - Increment an element's value attribute
  • increment @data-score - Increment a data attribute

Reactive Updates:

The count mirror below the buttons uses: on mutation of childList from #count to update whenever the counter changes. This watches the content of the #count element and mirrors the value, whoever wrote it. (It is upstream _hyperscript's spelling, so this page loads hyperfixi-hs.js; the larger bundles do not read it yet.)
